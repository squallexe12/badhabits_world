## 5. Frontend Güncellemeleri İçin Öneriler

### A. Mevcut `/pornografi` Sayfasına Eklenecekler
- `pornography.json` datasına **ülke bazlı izleme süresi** tablosu ekle

- COVID döneminde %25 artış vurgulayan bir **trend badge**

### B. Yeni Öneri: `/cinsel-saglik` Sayfası (21. Kategori)

Bu sayfa mevcut 20 kategoriye ek olarak eklenebilir.

**Alt bölümler:**
1. **STI/HIV Dünya Haritası** — HIV prevalansı coroplet haritası (SVG tabanlı, mevcut `CategoryDetail` bileşeni genişletilebilir)
2. **Gonore/Klamidya BigNumbers** — "374 milyon yeni vaka/yıl"
3. **HPV Farkındalık** — "Yaşam boyu bulaşma riski %80"
4. **Ergen Gebeliği Bar Chart** — bölge karşılaştırması

**Gerekli yeni dosyalar:**
- `src/app/cinsel-saglik/page.tsx`
- `src/data/sexual_health.json`

**Gerekli JSON tipi (`01-data-structure.md` güncellenecek):**
```ts
type SexualHealthEntry = Entry & {
  hivPrevalencePct?: number;
  teenBirthRate?: number;          // 1000 doğumda
  stiNewCasesMillions?: number;

};
```
